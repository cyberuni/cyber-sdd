Add the measured layer's engine and its `aced-bench` bin. `plan` prices a run of a suite's tasks without spending; `run --consent` runs them for real in throwaway git worktrees through a headless Claude Code; `compare` tells a real change from noise with permutation tests and a regression verdict. An arm can be a git ref, a package version, or one swapped file. Suites live under `.agents/aced/bench/<suite>/`, records under `.agents/aced/results/bench/<suite>/`.
