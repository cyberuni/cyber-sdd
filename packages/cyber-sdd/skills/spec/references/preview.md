# Preview a spec

Loaded by the `spec` skill's Preview mode.

1. Draft into a scratch folder. Draft the parent fully and one representative child fully.
2. List every remaining child with its outcome and its use case IDs. Do not draft them.
3. Report what the spec drops from the source, what it adds (actors, paths that miss a goal, decisions the source
   never made), and the open questions it surfaced. Report both parts, not a verdict on which artifact is better.

A preview is not a headless Write: it may ask the user, and its output is a sample, never a spec presented as ready.
It skips the research and the review, and records `Research: skipped, preview`.
