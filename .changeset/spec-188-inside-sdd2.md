The `spec` skill gains a Preview route. It drafts the parent and one child into a scratch folder, lists the other children, and reports what the spec drops from a source document and what it adds. The steps live in `references/preview.md`. A parent criterion that holds for every use case under it can cite `UC*`, which V5 expands to every use case of the parent and its children. A bare ID always means the spec's own, and a linked source's IDs are cited with the source's name. C10 now requires evidence that a criterion depending on an external system can be met.
