The `spec` skill now tells the two relationships between specs apart. A rung relation runs from the design spec to the functional spec beneath it. It is not parent and child, and it is not one to one, and the skill shows what each rung is named for, where it lives, and what its use cases are. A split stays on one rung, so a child is a design spec, never the functional spec. "Lower rung" now reads "a lower rung", since the functional spec and code and test are two rungs. The glossary gains rung (from truss), functional spec, and split.
